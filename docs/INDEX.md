# Intentional Communities research index

## Authority and mode

The default mode is P0 research. Article prose is outside scope unless the owner explicitly authorizes an editorial phase.

When an accepted checkpoint exists on `main`, read in this order:

1. `../README.md`
2. `../recovered/COMMUNITIES-RESEARCH-STATE.md`
3. the latest bounded report, currently `../recovered/COMMUNITIES-STANDALONE-RESEARCH-REPORT.md`
4. `../recovered/COMMUNITIES-EVIDENCE-LEDGER.csv`
5. `../recovered/COMMUNITIES-SOURCE-INVENTORY.csv`
6. `../recovered/COMMUNITIES-ARTICLE-GAP-BANK.md`
7. current discovery, update, test, and verification scripts

Before the first research checkpoint is merged, those files may exist only on the active volume PR branch. Do not reconstruct them from chat summaries.

## Evidence classes

Keep direct source evidence, author interpretation, reviewer-level reporting, alternative interpretation, process, outcome, verification leads, and bounded negative results distinguishable.

## Excluded material

Copyrighted PDFs, extracted full text, raw context dumps, caches, credentials, and private Drive identifiers remain outside Git.

## Plans

Accepted specifications and execution plans live under `docs/superpowers/` on the applicable research branch.
