# Main lesson — Record the branching process when the fission happens

**Status:** HIGH-VALUE RESEARCH-CONTROL / PRACTICAL

Parent→daughter genealogies can survive for decades while the actual mechanism of the split disappears from the record.

If a federation wants to learn how communities reproduce successfully, every fission should generate a standardized **branching record prospectively**, not depend on later reconstruction.

The Creative Tail repo now contains the reusable schema:
- `analysis/branching_process_covariates.md`

---

## B49-L01 — Record process and genealogy separately

Maintain linked datasets for:
1. parent→daughter genealogy and outcomes;
2. branching-process variables.

Do not make the process table look complete merely because the genealogy is complete.

## B49-L02 — Minimum fission record

At the time of split record:
- parent/daughter IDs and date;
- trigger for fission;
- partition mode (lot / mutual consent / volunteer / assignment / hybrid);
- whether group composition was fixed before destination was known;
- protected household/care units;
- initial group populations/households;
- leadership/skill/care balance;
- asset and **functional-capacity** split;
- transitional subsidy/support;
- dissent/transfers;
- later daughter survival/reproduction/human outcomes.

## B49-L03 — Confidence belongs to fields, not only whole events

A historical source can be excellent for:
- date;
- population;
- assets;
- land;

and silent about:
- how members were chosen.

Code uncertainty per variable. Preserve `unknown`.

## B49-L04 — Do not impute branch custom to an individual event

Generic Hutterite sources say different colonies/Leuts use volunteer, mutual-consent, balanced-group/lot and other practices.

That is context, not evidence that a particular named historical fission used that procedure.

## B49-L05 — Preserve planned and aborted daughter attempts

A reproduction study should ideally include:
- completed daughters;
- planned but abandoned daughters;
- postponed fissions;
- early failed/reabsorbed daughters;
- conflict secessions.

Otherwise process research is selected on successful completion.

## B49-L06 — Separate planned reproduction from conflict secession

A normal population-driven daughter and a faction leaving after serious internal conflict may have completely different:
- parent support;
- assets;
- composition;
- leadership;
- outcomes.

Do not pool them uncritically.

## B49-L07 — Record mother→daughter support as part of the mechanism

James Valley→Miami (1966) is a useful event-level example: sources document meticulous asset division and continued eggs/chickens from the parent until Miami could supply its own.

This support is part of the reproductive architecture, not noise to omit.

## B49-L08 — Distinguish support-inclusive from unaided robustness

A daughter can be a successful reproduction because the movement routinely supplies support.

Report separately where useful:
- daughter outcome with normal support architecture;
- scale/duration of inherited/subsidized support;
- later independent operation.

## B49-L09 — Rock Lake→Interlake is a high-confidence destination-blind event

The Supreme Court of Canada record documents that the Rock Lake members formed two groups **without knowing which group would move**, after which destination was decided by lot and assets were split roughly by membership.

This is an unusually strong event-level process record.

Do not infer unrecorded details such as family/skill-balancing criteria from generic Hutterite practice.

## B49-L10 — Current evidence is too sparse for lot-vs-consent outcome claims

The event-level partition-method sample is currently too sparse and uneven for a defensible causal comparison.

Do **not** manufacture a regression using Leut identity as a silent proxy for actual fission procedure.

---

# Research-center implementation rule

Every future federation-supported daughter-community formation should produce a branching-process record before memory and post-hoc narratives alter the evidence.

That record should later join:
- C005 reproduction metrics;
- member/household outcomes;
- asset/support exposure;
- destination-blindness/partition method;
- C020 representation effects.
